# 🎓 Teacher's Day Digital Scrapbook

A high-end, premium digital memory book created to celebrate Teacher's Day. This project combines the clean, minimalist aesthetic with the nostalgic, authentic feel of a physical scrapbook (polaroids, masking tape, handwritten notes).

## ✨ Features

*   **Physical Scrapbook Elements**: Layered polaroid frames, masking tape, and subtle handwritten notes using Google Fonts (Caveat).
*   **Smooth Animations**: Fluid scroll effects, hover states, and staggered fade-ins powered by Motion.
*   **Fully Responsive**: Beautiful editorial layout that works perfectly on both mobile and desktop screens.
*   **Customizable Sections**: Easily editable Teacher Profiles, Memory Gallery, Student Messages, and Thank You sections.

## 🛠️ Tech Stack

*   **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
*   **Language**: [TypeScript](https://www.typescriptlang.org/)
*   **Animation**: [Motion](https://motion.dev/) (formerly Framer Motion)
*   **Styling**: Inline styles and CSS for layout and glassmorphism effects.
